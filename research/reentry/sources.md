### SEDR 200 vs SEDR 300
The Gemini game manual says its source is "SEDR 200 - Rendezvous and Docking Configurations (Vol. 2)" [S2 p.6] but captions its figures "SEDR 300, Vol 2" [S2 p.20]. All four NASA documents carry "SEDR 300" on the cover and in every page header (checked on the page images of S6 pp.57, 58, 67, 103-106 and on the covers); the string "SEDR 200" does not occur in the OCR text of any of them. Resolution: the document is SEDR 300 Vol II (Rendezvous and Docking Configurations); "SEDR 200" on [S2 p.6] is a typo in the game manual. (S6 is the same title the game describes: "Rendezvous and Docking Configurations", Vol 2.)

### Page numbering for the NASA documents
PDF page differs from the manual's own printed number by a constant per section, not globally. Examples for S6: printed 3-21 = PDF 57; 3-22 = PDF 58; 4-2 = PDF 67; 4-5 = PDF 70; 4-38 = PDF 103; 4-39 = PDF 104; 5-3 = PDF 121; 5-16 = PDF 134; 9-9 = PDF 253; 9-56 = PDF 300; 10-21 = PDF 343. S8: printed 4-42 = PDF 116, 4-43 = PDF 117, 4-47 = PDF 121, 4-48 = PDF 122. Always cite PDF page, with the printed number and figure number alongside.

## License note
The game manuals carry no license statement for redistribution. S1 says its images and information are "based on information made public by NASA" and that its images are "public domain images from NASA" [S1 p.7], but the PDF as a whole (text, layout, any game-specific art) has no stated license. Treat as copyrighted: kept local in `raw/` (gitignored), only the URL is linked. Whether the panel drawings can be redistributed on the site is an open question.

## Page numbering
"p." = PDF page. Mercury (S1): in the front matter (pp. 4-13) PDF page equals the printed footer number. Gemini (S2): printed footer = PDF page up to PDF p.23; from PDF p.24 on, printed = PDF + 3 (PDF 24 = printed 27), and +4 from PDF p.42 (printed 46) onward; PDF pp.131+ have no printed numbers in the text layer (so PDF 132 is chapter X Landing). The Gemini table of contents uses the printed numbers, which do not match the PDF pages at all in the later chapters (e.g. TOC says Checklists p.156, the PDF has them at pp.144-147). Always cite PDF pages.
