## Notes on access
- `WebFetch` on mlb.com returned HTTP 406, so the glossary pages were downloaded with `curl` (browser User-Agent) and the page text extracted. The text quoted/paraphrased comes from the page body. Archive of the HTML is not kept in the repo.
- Glossary pages that do NOT exist (the site serves an empty template): `/glossary/standard-stats/inning`, `/ball`, `/strike`, and `/glossary/standard-stats/putout` (not read). For "inning", "ball", "strike" the rulebook definitions are used instead.
- Tried to find the official mlb.com URL of the rulebook: a web search found only a third-party wiki mirror and bookstores, nothing confirmed to serve this exact file. Not recorded.
- S69, S95, S133 are JSON from statsapi.mlb.com fetched with curl on 2026-10-29. The Stats API is the feed behind mlb.com stats pages; numbers can be revised later. S136 is the pitching equivalent used in note 06. IDs S56-S68 (note 04), S70-S94 (note 05) and S96-S132 (note 06) are glossary pages; S69/S95/S133/S136 are Stats API pulls and S134/S135 are MLB.com news articles.
